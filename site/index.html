Your coding agents, in separate rooms.

Work and personal. Client A and client B. One profile per repository, chosen for you when you launch, and the agent never sees across the wall.

Try it in seconds. Pick your system, copy, paste.

sha256 checked

Downloads one archive from the GitHub release, checks its SHA256, unpacks one file into this folder and runs it. The archive and the binary stay in this folder until you delete them or keep the binary (below). Nothing is installed anywhere else. Nothing leaves your machine.

Keep it

The snippet leaves the binary in the folder you ran it in. To keep it, move it to a folder on your PATH.

Linux and macOS

mkdir -p ~/.local/bin && mv agent-profile ~/.local/bin/

If agent-profile is then not found, add that folder to your PATH. In zsh, the macOS default: echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc, then open a new terminal.

Windows

New-Item -ItemType Directory -Force $HOME\bin | Out-Null; Move-Item -Force .\agent-profile.exe $HOME\bin\

Windows does not look in that folder yet. Add it once: [Environment]::SetEnvironmentVariable('Path', [Environment]::GetEnvironmentVariable('Path', 'User') + ";$HOME\bin", 'User'), then open a new terminal.

The release binaries are not code-signed, so macOS may refuse to open the downloaded file and Windows may ask before running it. If that happens, xattr -d com.apple.quarantine agent-profile on macOS or Unblock-File .\agent-profile.exe on Windows clears the mark. Whether either system asks depends on how the file arrived and on your settings.

Rust users

cargo install --locked --git https://github.com/ckir/aiprofiles --bin agent-profile agent-profile
