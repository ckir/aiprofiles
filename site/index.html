Why Agent Profile?

Privacy & Security

Zero-Trust Isolation

Never copies credentials, extracts tokens, or sends telemetry. Keeps personal configurations, client secrets, and memory graphs strictly quarantined across repository boundaries.

Deterministic Resolution

Mathematical Precedence

A rigorous 4-step precedence ladder: agent repo mapping → repository mapping → default_profile → error. Symlinks, worktrees, and submodules resolve to their canonical roots.

Empirical Verification

Evidence-Measured Claims

Twelve coding agents measured in an automated sandbox probe harness. Distinguishes between measured filesystem observations, vendor claims, and unmeasured assumptions.

Architecture: The LaunchPlan Contract

Agent Profile owns profile selection. The coding agent owns authentication and agent-specific configuration. The evidence determines what Agent Profile is allowed to claim.

Adapters Produce Data, Never Processes

Adapters inspect configuration paths and emit an immutable LaunchPlan. The centralized process launcher executes the target binary with a sterile environment, preventing ambient environment variable bleed and credential contamination.

Keep it

The snippet leaves the binary in the folder you ran it in. To keep it, move it to a folder on your PATH.

Linux and macOS

mkdir -p ~/.local/bin && mv agent-profile ~/.local/bin/

If agent-profile is then not found, add that folder to your PATH. In zsh, the macOS default: echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc, then open a new terminal.

Windows

New-Item -ItemType Directory -Force $HOME\bin | Out-Null; Move-Item -Force .\agent-profile.exe $HOME\bin\

Windows does not look in that folder yet. Add it once: [Environment]::SetEnvironmentVariable('Path', [Environment]::GetEnvironmentVariable('Path', 'User') + ";$HOME\bin", 'User'), then open a new terminal.

The release binaries are not code-signed, so macOS may refuse to open the downloaded file and Windows may ask before running it. If that happens, xattr -d com.apple.quarantine agent-profile on macOS or Unblock-File .\agent-profile.exe on Windows clears the mark.

Rust users

cargo install --locked --git https://github.com/ckir/aiprofiles --bin agent-profile agent-profile

Needs Rust 1.98.
