About Agent Profile

Local, privacy-first isolation for professional multi-agent software engineering.

Origins & Philosophy

As software engineers adopted multiple autonomous coding assistants across client contracts and open-source work, a critical failure mode emerged: global credential and state contamination. Launching an agent in an open-source clone inadvertently exposed private API keys and company prompt histories stored in default user home directories.

Agent Profile was created by Costas Kirgoussios to establish strict, deterministic compartment walls between repositories. Its design adheres to three unwavering tenets:

1. Agent Profile owns profile selection. The coding agent owns authentication and agent-specific configuration.

2. The evidence determines what Agent Profile is allowed to claim. No feature or isolation claim is made without empirical verification in an automated sandbox harness.

3. Never trust the repository. An untrusted repository must never be permitted to specify, override, or alter profile selection.

Privacy & Security Guarantees

  • Completely Local: Everything executes locally on your workstation. No cloud servers, no proxy relays, no centralized token storage.
  • Zero Telemetry: Agent Profile contains zero analytics SDKs, zero phone-home routines, and zero metric beacons.
  • Zero Token Extraction: We never copy, extract, decrypt, or log your API keys or OAuth access tokens.
  • Sterile Subprocess Environments: The process launcher executes child processes with explicit, clean environment maps to prevent accidental ambient variable leakage.
